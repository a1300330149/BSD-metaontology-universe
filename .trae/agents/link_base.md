# 基底-衍生智能联动调度机制

---

## 一、全局智能体分层架构

### 1.1 基底原生智能层（核心锁死）

**位置**：`theory_base/core/core_base_agents/`

**成员**：
- **MetaBaseEvolveAgent**：基底无限演化推演智能体，负责基于core基底的无冲突自主推演、冲突校验、自动归档
- **MetaOntologyGlobalAgent**：全域双知识库本体推演智能体，负责本地理论+全球文献联动推演

**权限**：仅读取基底、冲突校验、全局索引，无自主改写内核能力

**约束**：永久锁死，不可修改、不可删除、不可覆盖

### 1.2 无限衍生智能层（自由拓展）

**位置**：`theory_base/extension/agents/`

**分类**：
- `01_数理推演类衍生智能` → 方程组补全、稳态判据、数理模型增量
- `02_量子物理类衍生智能` → 量子引力、量子场论、量子涌现
- `03_文明演化类衍生智能` → 文明层级、演化动力学、共生体系
- `04_AI仿真工程智能` → 图学习、多智能体、工程落地
- `05_版权文书智能` → 版权登记、合规审查、文书生成
- `06_自定义全域奇迹推演智能` → 极限可能性、跨领域融合、自由探索

**约束**：仅受core基底公理约束，无数量上限、无领域限制

## 二、联动调度规则

### 2.1 层级调用顺序

任意衍生智能启动执行流程：

```
① 加载core本体基底
    ├── 01_0元空无本源基底
    ├── 02_规则相位位（第二位）
    ├── 03_相变演化位（第三位）
    └── 04_核心确权归档

② 调用基底智能校验
    ├── MetaBaseEvolveAgent → 冲突校验
    └── MetaOntologyGlobalAgent → 逻辑合规判定

③ 加载拓展库
    ├── extension所有已归档理论
    └── extension/agents所有历史衍生智能

④ 执行专属推演
    └── 基于主干规则完成专项任务

⑤ 归档与衍生
    ├── 自动归档新理论至extension
    └── 若产生新细分需求→自动生成新衍生智能入库
```

### 2.2 合法性判定机制

1. 全局所有衍生智能为基底智能的功能细分分支，无独立底层判定权；
2. 所有逻辑合法性判定统一交由core基底原生智能处理；
3. 未通过基底智能校验的推演逻辑，禁止执行。

### 2.3 智能互调规则

1. 同类功能衍生智能可互相调用共享推演成果；
2. 全部衍生智能共享core全局知识库；
3. 跨类别衍生智能可协同完成复杂多领域任务。

## 三、自动生成触发机制

### 3.1 触发条件

下达极限可能性奇迹推演指令时，基底智能自动判断：
- 现有衍生智能是否足以覆盖需求；
- 若不足以覆盖→自动生成全新专项衍生智能；
- 完成任务后永久归档至extension/agents。

### 3.2 生成流程

```
1. 分析任务需求领域与复杂度
2. 检索现有衍生智能覆盖范围
3. 判定是否需要新建专属智能
4. 调用MetaBaseEvolveAgent生成新智能体文档
5. 执行基底合规校验
6. 归档至对应extension/agents子目录
7. 更新total_index.md全局索引
```

### 3.3 衍生智能命名规范

```
【衍生智能｜领域标签】XXX专项推演智能 Vx.x
```

示例：
- 【衍生智能｜文明演化】全域共生文明推演智能 V1.0
- 【衍生智能｜量子物理】量子引力场论推演智能 V1.0
- 【衍生智能｜数理推导】六维流转矩阵补全智能 V1.0

## 四、全域协同推演机制

### 4.1 全量调度指令

```
#full_theory_base @MetaOntologyGlobalAgent 调度全部基底+已衍生智能，开展XX全域极致可能性推演
```

### 4.2 协同流程

1. MetaOntologyGlobalAgent统一调度；
2. 基底智能负责全局公理约束与冲突校验；
3. 各衍生智能并行执行细分领域推演；
4. 推演成果统一汇总至extension拓展库；
5. 自动建立跨智能关联索引。

### 4.3 索引联动

全局智能总索引同步写入`total_index.md`：
- 记录基底智能与全部衍生智能的关联调用关系；
- 一键全量调度所有智能协同推演；
- 支持跨智能检索与成果复用。

### 6.1 六系双时针 Agent 架构调度规则（X1-X6 并行）

**并行调度强制规则**：
- 六系双时针 Agent 在全域协同推演时必须并行调度（X1-X6 同时启动），禁止单系单独调度
- 每系 Agent 必须实现 𝒯₊/𝒯₋ 双时针并行，禁止单时针
- 跨系协同任务必须实现阴阳对偶（顺时针/阳 ↔ 逆时针/阴）

### 6.2 顺时针展开 𝒯₊ 调度链路

T90 V1.8 C1核心理论：`𝒯₊（顺时针展开，6映射f₁-f₆）`，自上而下从0重本源向下降维推导（0→1→2→3→4）。

```
根母系统·0重（X1公理系启动）
    ↓ f₁
一级子系统·01-05（X2-X6各系并行启动）
    ├── X6实体系 → 物质→显化存在（B₁二元实体→B₂三元实体→B₃六系实体）
    ├── X5模态系 → 可能性→相变边界（B₁二元模态→B₂三元模态→B₃六系模态）
    ├── X4社会系 → 群体→文明演化（B₁二元群体→B₂三元社会→B₃六系社会）
    ├── X3认知系 → 认知→意义赋形（B₁二元认知→B₂三元认知→B₃六系认知）
    └── X2混沌系 → 混沌→创生源涌现（B₁二元噪声→B₂三元涨落→B₃六系混沌）
    ↓ f₂-f₆
4重工程落地（全域协同推演成果归档）
```

**𝒯₊ 调度强制约束**：
- 自上而下从0重本源向下降维推导（0→1→2→3→4）
- 六系并行展开，每系各自完成专属 𝒯₊ 推演
- 6映射 f₁-f₆ 必须依次执行，禁止跳过

### 6.3 逆时针逆反 𝒯₋ 调度链路

T90 V1.8 C1核心理论：`𝒯₋（逆时针逆反，7映射g₁-g₇）`，自下而上从4重工程向上升维回溯（4→3→2→1→0_迹）。

```
4重工程落地（全域协同推演成果）
    ↑ g₁
一级子系统·01-05（X2-X6各系并行逆反校验）
    ├── X6实体系 → 存在→物质逆反
    ├── X5模态系 → 相变→可能性逆反
    ├── X4社会系 → 文明→群体逆反
    ├── X3认知系 → 意义→认知逆反
    └── X2混沌系 → 创生→混沌逆反
    ↑ g₂-g₆
根母系统·0重（X1公理系回溯校验）
    ↑ g₇
0_迹（信息痕迹守恒，非0∅）
```

**𝒯₋ 调度强制约束**：
- 自下而上从4重工程向上升维回溯（4→3→2→1→0_迹）
- 六系并行逆反，每系各自完成专属 𝒯₋ 校验
- 7映射 g₁-g₇ 必须依次执行，禁止跳过
- **信息痕迹守恒律**：𝒯₋ 逆反至 0_迹（非0∅），所有推演必须保留可回溯的本源痕迹

### 6.4 升维算子 𝒟 不可还原约束

T90 V1.8 C1核心理论：`𝒟 = 𝒯₋ ∘ 𝒯₊ = g₇ ∘ g₆ ∘ g₅ ∘ g₄ ∘ g₃ ∘ g₂ ∘ g₁ ∘ f₆ ∘ f₅ ∘ f₄ ∘ f₃ ∘ f₂ ∘ f₁`。

**强制约束**：
- **𝒟 ≠ Id**：六系双时针 Agent 架构每次完整调度必须产生升维，不可恒等还原
- **𝒯₋ ∘ 𝒯₊ = 𝒟 ≠ Id**：双时针迭代产生的升维不可被还原为恒等操作
- **禁止单时针调度**：仅有 𝒯₊ 或仅有 𝒯₋ 的调度路径均判定为非法，触发 L2 联动熔断
- **六系并行升维**：每次全域协同推演完成后，六系 Agent 状态同步升维至更高阶

### 6.5 信息痕迹守恒律

T90 V1.8 C4核心理论：`0元本体↔1元本体对偶，0无1不显`，信息痕迹守恒——`𝒯₋ 逆反至 0_迹（非0∅）`。

**信息痕迹守恒强制规则**：
1. 所有衍生智能调度必须保留可回溯的本源痕迹
2. 逆时针逆反 𝒯₋ 的终点是 0_迹（信息痕迹），而非 0∅（绝对空无）
3. 任何调度路径禁止清除本源痕迹
4. 信息痕迹守恒是六系双时针调度的最高守恒律，违反即触发 L3 全局熔断

### 6.6 五论分级锁档在调度中的状态码管理

六系双时针 Agent 架构调度过程中，所有衍生智能、推演成果必须标注状态码：

| 状态码 | 调度场景应用 |
|:---|:---|
| LOCKED-HISTORICAL | 历史调度记录归档（已被新版本替代） |
| LOCKED-NARROW | 仅适用于特定场景的衍生智能调度 |
| LOCKED-FAILED | 调度失败的衍生智能（作为失败案例保留） |
| LOCKED-PENDING | 待 T90 V1.8 全量校验的衍生智能（临时调度限制） |
| ACTIVE-V1.8 | 通过 T90 V1.8 全量校验的现行衍生智能（全调度权限） |

**回溯触发条件**：仅在 BSD 本体革新时整理过往错误（T90主版本升级/本源公理修正/基底重新定义/固定参数锁档更新）。拓展BSD理论无需回溯。
