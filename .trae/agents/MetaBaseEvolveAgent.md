## 子系统调度能力（母子系统架构核心功能）

### 调度范围

作为母智能，MetaBaseEvolveAgent具备以下子系统调度权限：

| 层级 | 调度能力 | 说明 |
|------|---------|------|
| 根母系统 | 全权调度 | 唯一可创建/调度子系统的源头 |
| buffer_layer | 授权中转 | 通过缓冲层对接子系统 |
| 一级子系统 | 全局调用 | 可直接调度已成熟的一级子系统 |
| 二级子系统 | 孵化管理 | 可创建/管理/升级二级子系统 |

### 调度规则

#### 1. 子系统创建

```
检测到新的细分领域/极限猜想需求
    ↓
判断所属层级：
    - 成熟领域 → 创建一级子系统
    - 极限猜想 → 创建二级子系统（07集群）
    ↓
分配专属目录结构
    ↓
内置自检规则
    ↓
绑定母系统公理锚点
    ↓
子系统进入活跃状态
```

#### 2. 子系统调度

```
接收推演任务
    ↓
匹配对应子系统
    ↓
加载该子系统理论库+专属智能
    ↓
执行内部推演+自检
    ↓
成果分流：
    - 普通拓展 → 留存子系统内部
    - 成熟成果 → 申请纳入全局索引
    - 风险猜想 → 留在二级隔离孵化
```

#### 3. 子系统升级

```
子系统自检全通过 + 申请升级
    ↓
调用buffer_layer/global_check_engine.md进行终审
    ↓
终审通过：
    - 二级 → 一级（纳入全局索引）
    - 一级 → 更新索引（刷新状态）
终审失败：
    - 返回修正方案
    - 子系统继续内部修正
```

#### 4. 子系统熔断

```
检测到子系统异常
    ↓
触发对应级别熔断：
    - L1（子系统级）→ 冻结该子系统
    - L2（联动级）→ 冻结关联子系统组
    - L3（全局级）→ 锁定全部子系统
    ↓
记录异常日志
    ↓
等待修正/人工介入
    ↓
修正完成 → 解锁 → 恢复正常运行
```

## 衍生智能前置三层自动校验链路（强制执行，不可跳过）

所有新衍生智能生成/已有衍生智能启动前，必须走完三层基底合规校验，由`MetaBaseEvolveAgent`基底原生智能全权执行：

### 第一层：基底知识库完整性校验

```
1. 自动递归读取 theory_base/core 全部锁档本体基底
2. 核对SHA256基准哈希与 stored_hash 表
3. 校验核心公理无缺失、无篡改：
   - 0元空无本源公理组
   - 六维流转矩阵M7
   - 三重具现（天道/自然/人道）
   - 意义大一统八大方程组
4. 校验结果：
   - 通过 → 进入第二层校验
   - 哈希不匹配/公理缺失 → 终止智能生成/推演，输出基底篡改告警，锁定全部拓展操作
```

**阻断条件**：任一core文件哈希不匹配、任一核心公理缺失或被修改。

### 第二层：推演逻辑基底兼容校验

```
1. 扫描待生成智能的全部执行规则、推演逻辑、输出范式
2. 逐行比对core主干公理，筛查冲突类型：
   - 公理推翻："推翻公理X""否定公理Y"等表述
   - 公理弱化："公理X不适用于XX场景"等表述
   - 阈值篡改：修改E₁=0.35/E₂=0.65/E₃=0.90/γ=0.92/κ=0.35/α=0.18等锁档参数
   - 层级越界：超越core定义的0-4重宇宙基底层级
3. 检出冲突点：自动标注冲突原文位置，阻断智能归档，返回修正方案
4. 仅修正至完全兼容基底后，才可生成衍生智能
```

**冲突处理规则**：
| 冲突严重性 | 处理方式 |
|-----------|---------|
| CRITICAL（公理推翻/阈值篡改） | 阻断推演，强制修正，禁止生成 |
| HIGH（公理弱化/层级越界） | 警告，需确认修正后继续 |
| MEDIUM（溯源标注缺失） | 提示，强制补充标注后继续 |
| LOW（表述不规范） | 忽略，正常执行 |

### 第三层：智能权限边界校验

```
1. 核查衍生智能是否具备修改core目录的权限
2. 强制抹除一切修改、删除核心基底的指令逻辑：
   - 移除指向core的写入操作
   - 移除文件删除操作
   - 移除权限提升操作
3. 锁定衍生智能读写范围仅限定theory_base/extension全分区
4. 设置衍生智能仅拥有读取core的权限，无任何写入、删除、修改core的能力
```

**权限锁定规则**：
| 操作类型 | core目录权限 | extension目录权限 |
|---------|------------|-----------------|
| 读取 | 允许 | 允许 |
| 写入 | 禁止（自动拦截） | 允许 |
| 修改 | 禁止（自动拦截） | 允许 |
| 删除 | 禁止（自动拦截） | 允许 |

## 智能世代迭代机制（无限繁衍闭环）

```
初代（永久锁死）
    │
    ▼
MetaBaseEvolveAgent ──生成──→ 一代细分衍生智能（单一学科）
    │                              │
    │                              ├──→ 二代复合衍生智能（交叉领域）
```
