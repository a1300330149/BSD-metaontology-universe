# Skill：BSD双向迭代验证管线（T90 V1.8 专属，自动校验理论与代码双向锚定）

> **理论来源**：T90 V1.8 §11.8.10-§11.8.12 + BSD-OrderArch-007
> **基底层级**：0重元道本源基底
> **协同关系**：本 Skill 为 Ontology_Theory_Guard 的专项深度校验补充，归属 C1 双向迭代算子公理（公理十一）落地验证管线。

## 触发时机

- 任何 bsd-oaps 工程代码提交前
- 任何 T90 V1.8 理论文档归档前
- Builder 批量任务执行后
- Ontology_Theory_Guard 校验通过后的专项深度校验

## 前置依赖

- 自动读取 `.trae/rules/meta_theory_constraint.md` 第8节 T90 V1.8 核心理论强制约束
- 自动调用 Ontology_Theory_Guard Skill 完成基础校验
- 自动读取 bsd-oaps/registry/constants.py 参数注册表

## 执行流水线（双时针并行校验）

### 1. 顺时针校验（T90→T0，自上而下）

从 T90 V1.8 理论文档出发，校验 bsd-oaps 工程代码是否完整实现五大核心理论：

#### 1.1 C1 双向迭代算子校验
- 检查 `bsd-oaps/bsd_engine/core/bidirectional_iteration_operator.py` 是否存在
- 校验 𝒯₊ 顺时针展开算子实现（6映射f₁-f₆）
- 校验 𝒯₋ 逆时针逆反算子实现（7映射g₁-g₇）
- 校验 𝒟 升维算子实现（𝒟=g₇∘...∘f₁）
- 验证对偶性定理：𝒯₋ ∘ 𝒯₊ = 𝒟 ≠ Id

#### 1.2 C2 六层多元进制校验
- 检查 `bsd-oaps/bsd_engine/core/six_level_base_emergence.py` 是否存在
- 校验 B₁二进制→B₂三进制→B₃六进制→B₄十进制→B₅十二进制→B₆ N进制 六层实现
- 验证层级涌现定理：|B_{k+1}| = |B_k| + Δ_k
- 验证层级不可逆性：低维不能反向生成高维

#### 1.3 C3 三个0.9同构定理校验
- 检查 `bsd-oaps/bsd_engine/core/three_nine_isomorphism.py` 是否存在
- 校验 0.9̇ ≅ 0.9π ≅ E₃=0.90 三重同构实现
- 验证共享系数 k₊=0.9 不可修改
- 验证三重投射维度映射（1维时间/2维时空/3维文明）

#### 1.4 C5 3×3粒子家族矩阵校验
- 检查 `bsd-oaps/bsd_engine/core/particle_family_matrix.py` 是否存在
- 校验个体性谱系(1,4,7)/变化性谱系(2,5,8)/关系性谱系(3,6,9) 实现
- 验证生点证圆机制（π=3为生点，3×3=9证圆）
- 验证双时针阴阳对偶（顺时针=奇数/阳，逆时针=偶数/阴）
- 验证数字位守恒（1+1+1+2+2+2=9）

### 2. 逆时针校验（T0→T90，自下而上）

从 bsd-oaps 工程代码出发，校验是否有代码无理论支撑：

#### 2.1 代码锚→理论锚回溯
- 遍历 bsd-oaps 所有 Python 文件
- 检查每个文件头部注释是否标注归属基底+对应公理+理论原文出处
- 检查每个类/函数是否有理论映射注释
- 标记"代码超前无理论支撑"的独立代码逻辑

#### 2.2 参数注册回溯
- 检查 `bsd-oaps/registry/constants.py` 是否注册全部7个新参数
- 检查 ALL_LOCKED_PARAMS 字典是否包含全部参数
- 检查 verify_params() 函数是否校验全部参数
- 标记未注册的硬编码参数

#### 2.3 信息痕迹守恒校验
- 校验 𝒯₋ 逆反至 0_迹（非0∅）
- 校验信息痕迹不可完全消除
- 校验升维算子 𝒟 不可恒等还原

### 3. 升维算子 𝒟 综合校验

- 执行一次完整 BSD 迭代（𝒯₋ ∘ 𝒯₊）
- 验证结果为升维状态（≠ Id）
- 输出升维报告

## 验证脚本

- 主验证脚本：`.trae/scripts/bidirectional_iteration_verify.py`
- 辅助验证脚本：`.trae/scripts/ontology_theory_guard.py`

## 输出报告

校验完成后生成《BSD双向迭代验证报告.md》存入 `archive/T90_V1.8_适配核验/` 目录：
- 顺时针校验结果（T90→T0）
- 逆时针校验结果（T0→T90）
- 升维算子 𝒟 综合校验结果
- 冲突清单与修正建议

## 冲突处理

| 等级 | 类型 | 处理方式 |
|------|------|----------|
| 严重 | 缺失四大算子模块 | 立即终止，输出缺失清单 |
| 高 | 参数未注册或值不匹配 | 终止执行，列出冲突清单 |
| 中 | 单时针实现（缺𝒯₊或𝒯₋） | 警告，要求补全双时针 |
| 低 | 注释不规范 | 自动修正，继续执行 |
