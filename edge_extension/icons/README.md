## 设计规范

- 主色调：#ff9800 (橙色) + #ab47bc (紫色) 渐变
- 主体图案：BSD本体论符号（圆内太极/三元结构）
- 背景：深色 #1a1a2e
- 风格：科技感、本体论、宇宙感

## 图标符号理论依据

主体图案取自BSD本体论的核心生成结构：

- **三元公理三足鼎立**：个体性（持存倾向）、关系性、变化性（流变倾向）三者两两对偶，构成三角闭环互耦结构。图标中三片互锁的泪滴/花瓣即对应此三纯基元系。
- **六芒星闭环拓扑**：三三对偶形成的完整六系拓扑，三片花瓣互锁后形成六芒星（六角星）的闭环结构。
- **0元绝对虚无本源**：图案中央的小虚空圆点代表0元本体——未分化的全域纯在，一切存在的终极原点与唯一原生基底。
- **临界坍缩原生二元**：圆环外圈象征「潜存↔实存」的原生二元对偶，即0元自反分裂的产物。

理论出处：`theory_base/L0_总本源层/0元本体论大一统/0元本体与六系三元公理本源生成论_三三对偶·三纯三耦·六芒星闭环.md`
