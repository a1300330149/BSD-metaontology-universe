# BSD 理论治理规则

> 来源：`.trae/rules/global.md` + `global_theory_base_rule.md` + `global_theory_rule.md`
> 适用范围：所有涉及 theory_base 操作、理论推演、智能体衍生的任务

## 基底不可破坏铁律

- `theory_base/core/` 内全部文件为锁档主干基底，**禁止修改、删除、新增、覆盖、弱化、推翻**任何公理、方程组、层级定义、SHA256 哈希、确权信息。
- 任何写入 core 目录的请求应被拒绝。衍生内容仅允许写入 `theory_base/extension/`。
- 推演前自动比对 core 基底逻辑，若与基底公理冲突则终止推演，输出冲突对比报告。
