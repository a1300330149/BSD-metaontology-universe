## 使用流程

### 诊断新拒稿事件

1. **提取关键词**：从期刊拒稿信/系统通知中提取拒稿理由关键词
2. **匹配映射表**：查阅"国际/国内期刊BSD诊断对照表"的"拒稿理由关键词→BSD诊断"映射表，匹配关键词
3. **获取BSD定性**：获取BSD诊断结论、公理依据、系别归属、五论真值
4. **判定诊断级别**：根据诊断分级标准判定A/B/C/D级
5. **记录元实验**：在对照表的"元实验拒稿记录表"中追加新记录
6. **理论溯源**：查阅"BSD诊断参数定义表"获取公理依据与参数定义
7. **T90/T91深化诊断**：对AI期刊、数字阶层期刊、跨学科基础期刊的拒稿事件，应用T90双时针失配定理与T91真伪协同判定进行深化诊断

### 定期归档

- 每季度将元实验记录归档至全域库
- 每年更新诊断映射表，补充新的拒稿模式
