## 1. 启用SOLO模式（场2）

### 目的
让Trae可以自动执行完整的六阶自治流水线，不需要你一步步指挥。

### 操作步骤

**第一步：打开SOLO模式**
1. 在Trae界面的右侧边栏，找到并点击「SOLO」图标（像一个机器人的图标）
2. 如果找不到，点击左上角的「视图」菜单 → 「打开视图」 → 选择「SOLO」

**第二步：创建SOLO任务**
1. 点击SOLO面板中的「创建任务」按钮
2. 任务名称填写：`六阶自治流水线`
3. 任务描述填写：`自动执行六阶自主科研闭环流水线`

**第三步：配置SOLO约束**
1. 在SOLO任务配置中，找到「前置约束」选项
2. 点击「添加约束」
3. 选择「读取文件」，然后选择项目中的 `.trae/rules/meta_theory_constraint.md`
4. 再点击「添加约束」，选择「读取文件」，然后选择 `scripts/autonomous_pipeline.py`

**第四步：启动SOLO**
1. 点击「开始任务」按钮
2. SOLO会自动执行六阶流水线，你只需要等待完成

### 预期结果
- SOLO会自动执行六个阶段：FO-EFS → SOD-DBS → TO-IDS → FO-CDGS → FO-ROS → SO-ARCLS
- 执行完成后会生成：
  - 理论代码割裂缺陷报告.md
  - 验收报表.md
  - 流水线日志.json

## 2. 导入版权归档Skill（场3）

### 目的
让Trae在归档文档时自动校验版权合规性，确保所有文档都有完整的确权扉页。

### 操作步骤

**第一步：打开技能管理**
1. 点击Trae界面右上角的「设置」图标（⚙️）
2. 在左侧菜单中选择「技能」

**第二步：导入Skill**
1. 在技能管理页面，点击「导入技能」按钮
2. 在弹出的文件选择框中，选择项目中的 `.trae/skills/Copyright_Archive_Guard` 文件夹
3. 点击「确定」

**第三步：设置自动加载**
1. 导入成功后，找到「版权归档专属守卫」技能
2. 点击技能右侧的「设置」按钮
3. 勾选「项目自动加载」选项
4. 点击「保存」

### 预期结果
- 技能名称：版权归档专属守卫
- 状态：已启用
- 自动加载：已开启
- 每次打开Builder时会自动挂载此技能

## 3. 配置MCP工具接入（场4）

### 目的
让Trae可以调用外部工具（如算力调度、图计算等），扩展系统能力。

### 操作步骤

1. 点击Trae界面右上角的「设置」图标（⚙️）
2. 在左侧菜单中选择「MCP」

**第二步：查看已有配置**
1. 在MCP页面中，点击「查看配置」
2. 可以看到我们已经创建的 `configs/mcp_tool_mapping.yaml` 配置文件
3. 这个配置文件定义了三界秩序（天道/自然/人道）的工具分配

**第三步：接入简单工具（以Python脚本为例）**
1. 点击「添加工具」按钮
2. 工具名称：`哈希校验工具`
3. 工具类型：`Python脚本`
4. 脚本路径：选择项目中的 `scripts/hash_verifier.py`
5. 点击「确定」

**第四步：测试工具调用**
1. 在Chat对话中输入：`调用哈希校验工具`
2. Trae会自动运行 `hash_verifier.py`，输出校验结果

## 常见问题解答

### Q1：终端命令输错了怎么办？
A：没关系，按 `Ctrl + C` 停止当前命令，然后重新输入正确的命令。

### Q2：脚本运行报错怎么办？
A：查看错误信息，通常是缺少依赖包。可以在终端中输入：
```
pip install -r requirements.txt
```

### Q3：找不到某个文件怎么办？
A：检查文件路径是否正确，确保项目目录是 `c:\Users\13003\OneDrive\桌面\3333333\Agent_v2`。

### Q4：SOLO任务卡住了怎么办？
A：点击「停止任务」按钮，检查日志中的错误信息，修复后重新启动。
