# 理论库目录说明

**路径**：`./theories/`
**用途**：存放本孵化独栋的所有推演理论草稿、阶段性成果、外部参考文献

---

## 使用说明

1. 本目录存放孵化期的所有推演理论草稿
2. 孵化期内容为待验证猜想，不代表正式体系结论
3. 升级为一级成熟独栋后，正式定稿将迁入对应成熟小区理论库

---

## 目录结构

```
theories/
├─ 草稿文档1.md          推演理论草稿
├─ 草稿文档2.md          推演理论草稿
└─ external_ref/         外部参考文献（开通管线后自动归档）
```
