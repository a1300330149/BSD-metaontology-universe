# 智能体目录说明

**路径**：`./agents/`
**用途**：存放本孵化独栋的专属子智能体

---

## 使用说明

1. 本目录存放孵化期的专属子智能体
2. 孵化智能体仅在本独栋内部生效，无全局调度权限
3. 随项目成熟度可逐步升级权限

---

## 目录结构

```
agents/
└─ 孵化推演智能体.md    专属孵化推演智能体
```

---

## 智能体权限

| 权限类型 | 范围 |
|---------|------|
| 读写范围 | 仅本独栋目录内 |
| 母核权限 | 只读白名单内基础公理 |
| 跨系统 | 无（完全隔离） |
| 管线权限 | 无（全断开） |
