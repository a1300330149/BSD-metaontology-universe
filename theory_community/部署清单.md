## 阶段七：配置定时自动运维（无人值守）

### Linux / macOS（cron 定时任务）

1. 执行 `crontab -e`；
2. 添加以下行（每日凌晨2点自动巡检生成报告）：

```bash
0 2 * * * cd /你的项目根目录 && /usr/bin/python3 .trae/scripts/daily_inspection.py >> .trae/logs/inspection_cron.log 2>&1
```

3. 保存退出，定时任务自动生效。

### Windows（任务计划程序）

1. 打开「任务计划程序」→ 创建基本任务；
2. 任务名称：全域本体社区每日巡检；
3. 触发器：每天，凌晨 02:00；
4. 操作：启动程序；
   - 程序：`python.exe` 完整路径
   - 参数：`.trae/scripts/daily_inspection.py`
   - 起始于：你的项目根目录完整路径
5. 完成后可手动运行一次验证。
