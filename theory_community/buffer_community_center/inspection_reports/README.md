# 全域本体社区巡检报告存放目录

本目录存放每日自动巡检生成的运维报告。

## 报告命名规范

```
全域本体社区每日巡检报告_YYYYMMDD.md
```

## 报告内容

每份报告包含：
- 母核庄园安全状态（哈希校验）
- 子系统社区总览统计
- 各子系统详细状态表格
- 异常告警与处置建议
- 今日运维结论

## 使用方式

```bash
# 手动生成当日报告
python .trae/scripts/daily_inspection.py

# 配合系统定时任务每日自动执行
# Windows: 任务计划程序
# Linux: crontab
```

## 注意事项

- 全程纯读取校验，不修改任何业务配置
- 不触碰核心基底，符合基底不动原则
- 报告自动归档留存，可追溯历史状态
