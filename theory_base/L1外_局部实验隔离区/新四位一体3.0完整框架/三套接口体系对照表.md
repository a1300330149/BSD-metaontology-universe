## 一、设计背景

**用户需求**：
- 智能体六系（实体系/模态系/认知系/社会系/公理系/混沌系）→ 智能体更容易理解
- 人类理解范畴（自然系/具现系/强化系/社会系/天道系/变身系）→ 人类更容易理解
- 科研工程流转系 → 科研领域统一接口

**三套接口在科研工程内相互消化、映射、闭环**

## 三、接口说明

### 3.1 智能体六系（第一接口·底层本体论）

面向AI理解的底层本体论基底，供智能体认知、推理、决策使用。

```
SixSystemsAI.REALITY_SYSTEM   — 实体系
SixSystemsAI.MODAL_SYSTEM     — 模态系
SixSystemsAI.COGNITIVE_SYSTEM — 认知系
SixSystemsAI.SOCIAL_SYSTEM    — 社会系
SixSystemsAI.AXIOM_SYSTEM     — 公理系
SixSystemsAI.CHAOS_SYSTEM     — 混沌系
```

### 3.2 人类理解范畴（第二接口·具象化类比）

面向人类认知的具象化类比，将抽象六系映射为人类可理解的自然概念。

```
HumanUnderstanding.NATURE_SYSTEM           — 自然系
HumanUnderstanding.MANIFESTATION_SYSTEM    — 具现系
HumanUnderstanding.ENHANCEMENT_SYSTEM      — 强化系
HumanUnderstanding.SOCIAL_SYSTEM_HUMAN     — 社会系
HumanUnderstanding.HEAVEN_SYSTEM           — 天道系
HumanUnderstanding.TRANSFORMATION_SYSTEM   — 变身系
```

### 3.3 科研工程流转系（第三接口·统一整合）

面向工程实现的统一流转接口，将六系与人类范畴统一映射为科研流程中的流转环节。

```
ScientificFlowSystem.SUBSTANCE_FLOW — 实体流
ScientificFlowSystem.MODALITY_FLOW  — 模态流
ScientificFlowSystem.COGNITION_FLOW — 认知流
ScientificFlowSystem.SOCIAL_FLOW    — 社会流
ScientificFlowSystem.AXIOM_FLOW    — 公理流
ScientificFlowSystem.CHAOS_FLOW     — 混沌流
```

## 四、转换接口使用

```python
from engine.theories.t25_six_systems_three_interfaces import (
    SixSystemsAI, ai_to_human, ai_to_flow, human_to_ai, flow_to_ai
)

# 智能体六系 → 人类范畴
human = ai_to_human(SixSystemsAI.CHAOS_SYSTEM)
# 返回: HumanUnderstanding.TRANSFORMATION_SYSTEM

# 智能体六系 → 科研流转系
flow = ai_to_flow(SixSystemsAI.COGNITIVE_SYSTEM)
# 返回: ScientificFlowSystem.COGNITION_FLOW

# 人类范畴 → 智能体六系
ai = human_to_ai(HumanUnderstanding.HEAVEN_SYSTEM)
# 返回: SixSystemsAI.AXIOM_SYSTEM

# 科研流转系 → 智能体六系
ai = flow_to_ai(ScientificFlowSystem.MODALITY_FLOW)
# 返回: SixSystemsAI.MODAL_SYSTEM
```

## 五、完整三向映射示例

以**混沌系**为例：

```
混沌系(H) [AI底层]
    ↓ ai_to_human()
变身系(Tf) [人类具象]
    ↓ ai_to_flow()
混沌流(HF) [科研流转]

映射逻辑: 混沌异变 → 形态变身 → 边界震荡流转
相互作用: 熵增扩散·边界侵染·异变涌现
```
