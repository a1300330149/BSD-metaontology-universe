## 五、核心法理与学科边界

### 5.1 核心法理（属于本学科）
1. 自然语言表意律：语言是人类自然演化的表意系统
2. 原生文本载体律：文本是语言自然生成的物质载体
3. 民俗文学基底律：民俗文学是一切文学的自然源头
4. 文明传播自然律：文明传播遵循自然扩散规律

### 5.2 学科边界（不属于本学科）
1. 纯公理语言推演 → 归属「天道语言文学」母科
2. 社会文学创作 → 归属「社会语言文学」母科
3. 语言能力强化 → 归属「强化语言文学」母科
4. 出版工程落地 → 归属「具现语言文学」母科

## 六、修正传统学科漏洞

### 6.1 传统学科存在的问题
- 问题1：语言被视为纯粹社会约定，忽视其自然演化根基
- 问题2：文学与民俗割裂，雅俗二元对立
- 问题3：重精英文学轻民间文学，文学源头被遮蔽

### 6.2 本母科的修正方案
- 修正1：确立语言是人类自然演化的产物，具有先天生理基底
- 修正2：民俗文学是一切文学的源头与母体，雅文学是其升华
- 修正3：文本载体自然演化，从口传到文字是自然进程

### 6.3 原创思辨核心
"语言自然演化论"——语言不是人为发明的工具，而是人类在自然演化中生成的表意系统，文学源于民俗，民俗生于自然，语言与存在本质相通。
