# 六系体系核心公理与规律总览

---

## 一、六系基础本体定义（三元公理耦合衍生）

六系是「个体性、关系性、变化性」三元本原公理，通过**单系独显+双系耦合**穷尽生成的六大存在极性，是所有实存、演化、文明、个体的底层功能模态。

| 系别 | 三元耦合方式 | 核心功能 | 定位 |
|------|-------------|----------|------|
| **强化系** | 个体性独显 | 自持基底、个体边界、自我同一性、主体存续 | 个体演化的绝对起点 |
| **社会系** | 关系性独显 | 秩序载体、集群联结、公共规则、共在稳态 | 集体结构的核心框架 |
| **变身系** | 变化性独显 | 演化动力、形态迭代、范式更新、层级跃迁 | 所有流变的动力源 |
| **具现系** | 个体性+关系性耦合 | 落地载体、自性外化、造物产出、价值落地 | 精神向物质转化的唯一通路 |
| **天道系** | 关系性+变化性耦合 | 顶层格局、范式突破、边界开拓、全域升维 | 群体文明演化的绝对起点 |
| **自然系** | 变化性+个体性耦合 | 底色锚点、本源传承、禀赋积淀、稳态续航 | 所有演化的根基保底层 |

## 二、核心刚性公理（底层运行铁律）

### 1. 双起点不对称公理

- **个体演化永远从强化系始发**（自下而上），以个体自持为根基逐级升维；
- **群体文明演化永远从天道系始发**（自上而下），以顶层范式解锁为源头逐级落地；
- 二者为六系体系的上下两极，天生相克（个体边界固化vs全域边界消融），可通过中间系中转达成高阶相生。

---

### 2. 亲缘传导公理（不可跳级·固定链路）

意义能量只能沿固定亲缘链路逐级传导，**无直达路径、不可跨级跳层**，共两条对称传导路径：

#### 逆时针链路（群体天道始发）
```
天道系（本系始发）
→ 变身系（第一亲缘承接）
→ 自然系
→ 强化系
→ 具现系
→ 社会系
→ 回流天道系
```

#### 顺时针链路（个体强化始发）
```
强化系（本系始发）
→ 具现系（第一亲缘承接）
→ 社会系
→ 天道系
→ 变身系
→ 自然系
→ 回流强化系
```

#### 配套规则
单纯的变身迭代、单纯的社会结构变革，仅能完成精神/意识层面的蜕变；个体的物质性能力改造，必须经由自然禀赋改造或具现物工具赋能才能实现。

---

### 3. 意义层级公理

#### （1）本系盈余不递减规则
始发本系自身意义充盈、盈余自持，**始发值100意义单位，本系内部不发生衰减**；衰减仅从第一个外溢亲缘承接系正式启动。

#### （2）逐级固定衰减规则
每向下传递一个亲缘层级，意义理论生产量固定衰减20单位，最终回流始发本系时，本轮闭环意义归零。

| 层级 | 个体顺时针 | 群体逆时针 |
|------|-----------|-----------|
| 本系始发 | 强化系 100 | 天道系 100 |
| 第一承接 | 具现系 100 | 变身系 100 |
| 第二承接 | 社会系 80 | 自然系 80 |
| 第三承接 | 天道系 60 | 强化系 60 |
| 第四承接 | 变身系 40 | 具现系 40 |
| 末端 | 自然系 20 | 社会系 20 |
| 回流 | 强化系 0 | 天道系 0 |

#### （3）生产量/利用量二分规则
- 层级标注数值为**理论意义生产量（传导基准上限）**，100仅为基准产能，绝非绝对天花板；
- 真实落地的「意义利用量」可偏离理论值：
  - 体系异化、链路切断 → 利用量低于理论值 → **异化损耗量**
  - 工具跃迁、方法升维 → 利用量超越理论生产量 → 正向跃迁空间
- **异化差值 = 理论生产量 - 真实利用量**，正值为损耗，负值为跃迁增益，可量化衡量体系健康度。

#### （4）全域总量守恒规则
全域意义总能量不增不减，仅在不同层级、不同形态间转化；局部衰减、局部损耗均为层级现象，不改变全域总能量。

### 4. 单系截断稳态公理

六系任意单一系被完全截断，不会直接崩溃归零，而是各自生成专属的稳态形态，对应全域不同存在层级：

| 截断系别 | 稳态类型 | 核心特征 | 对应层级 |
|---------|---------|----------|---------|
| **截断强化系** | 波动循环稳态 | 个体边界周期性崩塌重构，陷入「归0-非0」无限治乱循环 | 动态存续稳态 |
| **截断天道系** | 固化不崩稳态 | 顶层范式锁死，其余五系正常运转，有迭代无升维 | 五元残缺态 |
| **截断具现系** | 文明失语稳态 | 造物生产停滞，无法向外落地输出意义，长期停滞但存续 | 封闭原始部落态 |
| **截断自然系** | 本源畸变稳态 | 文明失根、个体失性，依托人造信仰/异化秩序维系稳定 | 神权种姓文明态 |
| **截断社会系** | 二元撕裂稳态 | 集体秩序崩塌，群体分裂对立，陷入零和博弈 | 二元对立态 |
| **截断变身系** | 静态遗存稳态 | 演化完全冻结，存在坍缩为孤立自持实体 | 一元遗存态 |

---

### 5. 闭环递归公理

- 当时针走完完整传导链路、回归始发本系时，本轮传导的意义彻底归零，**本系无法在本次闭环内获得二次赋能**；
- 若本系已完成升维跃迁，也无法从本次闭环中获取新增意义；
- 闭环终结后，若要开启新一轮意义传导，必须等待新的范式解锁/个体破局。

---

### 6. 跃迁中转公理

- 若传导过程中某一中间系发生升维跃迁，该系会成为**意义中转站**，释放60单位新增意义能量，触发全域意义大爆发；
- 跃迁中转可打通体系两极（强化-天道）的相克属性，将顶点对立转化为高阶相生，释放最大量级的文明动能；
- 工业革命的具现系跃迁、信息革命的技术跃迁，均符合此规律。

## 三、衍生通用规律

### 1. 降维判定
维度冻结、系别截断、链路断裂，均为负向降维；层级越低，稳态越僵化、演化空间越小。

### 2. 升维判定
补齐截断系别、打通传导链路、中间系跃迁，均为正向升维；六系全通、相生链路满转，为最高阶完备升维态。

### 3. 文明周期规律
所有文明周期均遵循「天道解锁→逐级传导→跃迁爆发→闭环见顶→矛盾激化→降维坍缩→稳态锁死」的通用演化路径，完全匹配0-6元全域层级体系。
