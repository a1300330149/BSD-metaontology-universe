## 六系详细定义

### 第1系：R / 实体系 / 具现系 / 实体流
- **核心特征**：物质实体、具现固化、客观存在
- **典型领域**：物理学、化学、生物学、地理学
- **九界归属**：主要驻在物质实体界（R+）
- **五论权重**：正论为主（稳态实证）

### 第2系：M / 模态系 / 自然系 / 模态流
- **核心特征**：自然演化、试错模态、信息试错
- **典型领域**：生物学进化论、信息论、复杂性科学
- **九界归属**：主要驻在虚拟模态界（M+）
- **五论权重**：逆论为主（探索突破）

### 第3系：C / 认知系 / 强化系 / 认知流
- **核心特征**：认知强化、意识迭代、学习进化
- **典型领域**：心理学、神经科学、AI认知科学
- **九界归属**：主要驻在精神意识界（C+）
- **五论权重**：正论为主（稳态认知）

### 第4系：S / 社会系 / 社会系 / 社会流
- **核心特征**：社会秩序、集群共生、规则构建
- **典型领域**：社会学、经济学、政治学、法学
- **九界归属**：主要驻在社会秩序界（S+）
- **五论权重**：正论为主（稳态秩序）

### 第5系：A / 公理系 / 天道系 / 公理流
- **核心特征**：公理裁决、顶层统合、逻辑基底
- **典型领域**：数学、逻辑学、哲学基础、元理论
- **九界归属**：主要驻在全域统合界（A+）和神仙公理界（A++）
- **五论权重**：真论为主（终极真理）

### 第6系：H / 混沌系 / 变身系 / 混沌流
- **核心特征**：混沌异变、跨界变身、熵增崩坏
- **典型领域**：混沌理论、突变论、跨界研究
- **九界归属**：主要驻在地府魔界（H-）和克苏鲁混沌界（H?）
- **五论权重**：谬论为主（熵增崩坏）

## 六系正交关系

```
        公理系(A)/天道系
           ↑
  认知系(C)/强化系 ←→ 社会系(S)/社会系
           ↓
      模态系(M)/自然系 ←→ 实体系(R)/具现系
           ↓
      混沌系(H)/变身系
```
