```
母科总能级 = Σ(wi × Li)

  wi = 六系权重系数（i ∈ {天道,自然,社会,强化,具现,变身}）
  Li = 本母科在六系上的能级值 (0~1)
```

```
肉身总能级   = w物 × L物  （物质界贡献）
```

## 六、无限之子能级展开模型

```
母科能级（E1，Lv3级）
    │
    ├── E2分支能级提升（Lv3 → Lv4）
    │    运算：E²
    │    能级提升：0.5 → 0.7
    │
    ├── E3应用能级提升（Lv4 → Lv5）
    │    运算：↑↑
    │    能级提升：0.7 → 0.9
    │
    └── E4超运算能级（Lv5 → Lv5+）
         运算：↑ⁿ
         能级提升：0.9 → 1.0+（超阈）
```

**能级生长与超运算同步**：能级越高，超运算层级越高，学科分支越细密。
