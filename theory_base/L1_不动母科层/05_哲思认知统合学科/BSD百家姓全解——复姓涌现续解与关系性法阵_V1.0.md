- 合一：东方=$0_\text{义} \times 0_\text{空}$——"日出之方"。佛道讲"东方妙喜世界"。

$$\boxed{\text{闻人}(0_\text{反} \times 0_\text{空}) \times \text{东方}(0_\text{义} \times 0_\text{空}) = 0_\text{义}(\text{闻道入方})}$$
