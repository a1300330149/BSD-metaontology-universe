# BSD六系统一命名规范 V2.0

## 一、命名规范说明

### 问题背景
之前出现"天道系/地道系/人道系"与"时间系/空间系/关系系"的命名混乱

### 解决方案
采用**双维度命名体系**：
- 维度一：存在论维度（天道/地道/人道）
- 维度二：关系论维度（时间/空间/关系）

## 二、统一命名表

| 维度 | 标准名称 | 别名 | 说明 |
|-----|---------|------|------|
| 存在论 | 天道系 | 超越系、绝对系 | 超越性存在的集合 |
| 存在论 | 地道系 | 基础系、物质系 | 基础性存在的集合 |
| 存在论 | 人道系 | 主体系、心灵系 | 主体性存在的集合 |
| 关系论 | 时间系 | 时序系、演化系 | 时序关系的集合 |
| 关系论 | 空间系 | 广延系、形态系 | 广延关系的集合 |
| 关系论 | 关系系 | 关联系、结构系 | 关联关系的集合 |

## 三、维度关系图

```
存在论维度（纵向）
├── 天道系（超越）
├── 地道系（基础）
└── 人道系（主体）
         ↕ 耦合
关系论维度（横向）
├── 时间系（时序）
├── 空间系（广延）
└── 关系系（关联）
```

## 四、使用规则

1. **文档命名**：使用标准名称，避免别名
2. **代码注释**：使用标准名称，保持一致性
3. **跨引用**：使用"存在论维度·天道系"或"关系论维度·时间系"等格式
4. **新命名**：需提交审核，纳入规范表
