## V6.0改进说明

### 改进1：新兴软件类型识别
```
新增关键词覆盖：
  • 3D软件（Blender）→ 变身系
  • 办公软件（WPS Office）→ 社会系
  • 编程工具（TRAE SOLO CN）→ 天道系
  • 游戏平台（Steam）→ 变身系
  • 下载工具（Thunder）→ 社会系
  • AI工具（KimiData）→ 天道系
  • 硬件驱动（Intel）→ 强化系
  • 分区工具（Aomei）→ 强化系
```

### 改进2：多功能复合软件多归属
```
支持一个软件同时归属多个六系：
  • 云存储软件 → 自然系 + 社会系
  • 音乐平台 → 变身系 + 社会系
  • 游戏平台 → 变身系 + 社会系
  • 邮件系统 → 社会系 + 自然系

判定规则：分数达到主系统50%以上的系统纳入多归属
```

### 改进3：深度嵌套结构拆解
```
扫描深度从4层增加到5层
对嵌套目录进行递归拆解：
  • 游戏目录（Games/game2）→ 拆解子游戏
  • 编号目录（11/22/33）→ 拆解内部内容
  • Mod目录 → 拆解Mod资源
```
