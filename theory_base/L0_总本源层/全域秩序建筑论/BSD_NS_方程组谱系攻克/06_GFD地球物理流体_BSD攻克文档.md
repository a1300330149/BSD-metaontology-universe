## 二、GFD 核心方程组

### 2.1 准地转方程（Quasi-Geostrophic Equation）

```
∂q/∂t + v·∇q = f₀ (∂ψ/∂x · ∂q/∂y − ∂ψ/∂y · ∂q/∂x) + κ∇²q
```

其中：
- **位势涡度** q = f + ∇²ψ + (N²/f₀) ∂²ψ/∂z²
- **流函数** ψ 满足 v = (∂ψ/∂y, −∂ψ/∂x)
- **Rossby参数** β = df/dy，表征行星旋转效应的纬度梯度
- **Brunt-Väisälä频率** N，表征层结稳定性

### 2.2 涡度方程（Vorticity Equation）

```
∂ω/∂t + (v·∇)ω = (ω·∇)v − f(∇·v) + ν∇²ω + βvᵧ
```

其中：
- **相对涡度** ω = ∇×v
- **行星涡度** f = 2Ωsinφ
- **散度项** ∇·v 对应压缩/膨胀效应
- **黏性项** ν∇²ω 表征耗散

### 2.3 BSD 层级重构

将上述方程组投影到BSD层级坐标系：

```
┌─────────────────────────────────────────────────┐
│  L₀: 全域度规基底                              │
│      ↓ 拓扑稳态投影                             │
│  L₁: Rossby参数 β = κ/R₀ (拓扑稳态守恒量)      │
│      ↓ 相位场耦合                               │
│  L₂: 涡旋场 ω = Im[κ·exp(iφ_helix)]           │
│      ↓ 层级能量传递                             │
│  L₃: 能量级串 E(k) ∝ k^(-α) · L^(-β_BSD)     │
│      ↓ 气候投影                                 │
│  L₄: 气候变率 = BSD层级共振模式                 │
└─────────────────────────────────────────────────┘
```

## 三、关键现象与BSD对应

### 3.1 涡旋生成

| GFD视角 | BSD视角 |
|---------|---------|
| 纬向切变不稳定 → 涡旋成对生成 | κ相位场螺旋的拓扑缺陷对生成 |
| 正压/斜压不稳定能量释放 | BSD层级L₂→L₃能量跃迁 |
| 涡旋尺度与Rossby半径相关 | 螺旋半径r_helix = R₀/√κ |

**BSD表述**：涡旋 = κ相位场螺旋的拓扑孤子解，其稳定性由Rossby参数（拓扑稳态量）保证。

### 3.2 能量级串

```
大气能量谱（观测）：
  尺度 → 能量
  行星尺度 → 动能/势能峰值
  天气尺度 → 涡旋动能级串
  湍流尺度 → 黏性格点耗散

BSD层级对应：
  L₁（行星尺度） → Rossby模态
  L₂（天气尺度）  → 涡旋κ相位
  L₃（中尺度）    → 螺旋级串
  L₄（湍流尺度）  → 层级耗散
```

**BSD表述**：能量级串 = BSD层级结构中能量从L₁向L₄的逐级传递，谱指数α与层级间距直接相关。

### 3.3 气候变率

| 时间尺度 | GFD现象 | BSD层级 |
|----------|---------|---------|
| 日-周 | 天气波动 | L₂ 涡旋κ相位振荡 |
| 月-季 | 季节环流调整 | L₂→L₃ 能级跃迁 |
| 年-年代 | ENSO/PDO | L₃ 层级共振模式 |
| 世纪以上 | 古气候变率 | L₄ 长期拓扑演化 |

**BSD表述**：气候变率 = BSD层级共振的多频叠加，可预测性由层级耦合强度决定。

## 四、BSD 核心定理

### 定理一：能量级串的BSD层级结构定理

**陈述**：在GFD-BSD映射下，大气能量级串严格对应BSD四层结构（L₁→L₄），且：

```
E_total = Σᵢ₌₁⁴ E(Lᵢ) · exp(−γ·|i−j|)
```

其中 γ 为层级耦合衰减因子，E(Lᵢ) 为第i层的模态能量。

**证明思路**：
1. 从准地转方程出发，对位势涡度做尺度分离
2. 投影到BSD基底（L₀-L₄），利用正交性得到层级展开
3. 证明谱能量 E(k) ∝ k^(-2β_BSD-1)，与观测谱一致
4. 验证层级间能量传递的单向性（级串方向锁定）

**意义**：为长期气候模拟提供解析化的参数化方案，消除亚网格尺度的参数化误差。

---

### 定理二：气候可预测性的BSD判据

**陈述**：设气候系统初始状态为 ψ₀ ∈ H^s（BSD Sobolev空间），则可预测时间尺度 T_pre 满足：

```
T_pre ≤ C · ‖ψ₀‖_{H^s}^(-δ) · (κ/β)^ε
```

其中 C, δ, ε 为BSD普适常数，κ 为相位场耦合强度，β 为Rossby参数。

**证明思路**：
1. 将气候演化表述为BSD层级动力系统
2. 利用拓扑稳态量（Rossby参数）构造Lyapunov函数
3. 估计非线性项的增长速率，得到可预测性上界
4. 验证该判据与Lorenz经典可预测性的兼容（δ=1时退化为Lorenz界）

**意义**：定量界定气候模拟的有效预测范围，为数值模式改进提供严格边界条件。

## 五、攻克难点分析

### 5.1 长期气候模拟稳定性

| 难点 | BSD攻克路径 |
|------|------------|
| 数值模式漂移 | BSD拓扑稳态投影：将物理变量投影到Rossby不变量子空间，保证长期积分守恒 |
| 能量守恒破坏 | BSD层级能量约束：在每层施加能量通量闭合条件 |
| 混沌累积误差 | BSD可预测性判据作为自适应步长控制：当误差超界时自动切换层级 |

### 5.2 多尺度相互作用

**核心困难**：GFD中行星-天气-湍流尺度的跨尺度能量交换难以解析。

**BSD方案**：
```
跨尺度作用 = Σᵢ Σⱼ₌ᵢ±₁ g_{ij} · Φ_i ⊗ Φ_j
```
其中 g_{ij} 为BSD层级耦合张量，Φ_i 为第i层的相位场模态。

通过截断到近邻层（只考虑相邻层耦合），将无穷维问题约化为4×4耦合系统，计算量降低1-2个数量级。

### 5.3 参数化

**传统参数化问题**：亚网格尺度效应需经验参数化，缺乏物理约束。

**BSD参数化方案**：
- **涡旋参数化**：直接用κ相位场螺旋的拓扑指标（缠绕数w）替代经验涡旋扩散系数
- **边界层参数化**：利用BSD层级L₃→L₄的边界条件闭合，无需经验混合长度
- **辐射参数化**：将辐射传输投影到BSD频率层级，用层级跃迁概率替代灰体假设
